# Student Management System

## Description
A Student Management System developed using Node.js, Express.js, and MySQL. This project performs CRUD operations through REST APIs.

## Features
- Add Student
- View Students
- Update Student Details
- Delete Student
- MySQL Database Integration
- RESTful API Development

## Technologies Used
- Node.js
- Express.js
- MySQL
- Thunder Client

## API Endpoints

### Get All Students
GET /students

### Get Student By ID
GET /students/:id

### Add Student
POST /students

### Update Student
PUT /students/:id

### Delete Student
DELETE /students/:id

## How to Run

1. Install dependencies

```bash
npm install
```

2. Start server

```bash
node server.js
```

3. Open

```text
http://localhost:3000/students
```
